# 原曲を声で編集する（仕様案）

> 原曲4曲（AI で作った MIDI）から1曲を選び、体験者の声に合わせて編集する仕組みの仕様です。
> まだ案です。設計図・楽譜の形を変える部分（「6. 形の変更」）は、`docs/interfaces.md` の 10 に従って入力1・曲1・曲2で決めてから実装します。

## 1. 全体の流れ

```
質問の答え ─→ Traits ─→ 原曲を選ぶ（A〜D）─┐
声 ─→ features ─→ キー・音域・息っぽさ ──┼→ 設計図 ─→ compose() ─→ 楽譜 ─→ 音・WAV
叩き方 ─→ bpm・groove ────────────────┘        ↑
                                     原曲の JSON（src/music/songs/）
```

- 入力1（`toBlueprint`）: 原曲を選び、声の特徴を設計図の数字にする
- 曲1（`compose`）: 原曲の JSON を読み、移調・音域の変更・テンポとノリの反映をして楽譜にする
- 曲2（`sound.js`）: 息っぽさに合わせてリバーブとパッドの音色を作る

## 2. 原曲（MIDI）の作り方

AI で MIDI を書き出すとき、次をそろえる。そろっていないと編集できない。

| 項目 | 決まり |
|---|---|
| 曲数 | 4曲（A・B・C・D） |
| 拍子 | 4/4 |
| 長さ | **20小節**（1問＝2小節 × 10）。イントロ・アウトロ（声）は含めない |
| キー | 1曲の中で転調しない。キー（例: D dorian）を曲ごとに記録する |
| テンポ | 何でもよい（体験者の叩いた速さで決め直す） |
| パート | **トラックを4つに分ける**。トラック名は `melody`・`pad`・`bass`・`drums` |
| メロディ | 単音（和音にしない）。音域は C4〜C6 くらい |
| パッド | 和音。音域は C3〜C5 くらい |
| ベース | 単音。音域は C1〜C3 くらい |
| ドラム | General MIDI の番号: キック 36、スネア 38、ハイハット 42（それ以外は使わない、または無視する） |

4曲の性格（案）。どの曲になっても体験者が楽しめるように作る。

| 曲 | 雰囲気 | 選ばれる人（案） |
|---|---|---|
| A | 明るく軽快 | 外向性が高い・情緒が安定 |
| B | 明るいが揺らぎがある | 外向性が高い・繊細 |
| C | 穏やかで落ち着いた曲 | 外向性が低い・情緒が安定 |
| D | しっとりした曲 | 外向性が低い・繊細 |

## 3. MIDI → JSON

MIDI はそのまま使わず、**一度だけ JSON に変換してリポジトリに入れる**（`src/music/songs/A.json` 〜 `D.json`）。ブラウザで MIDI を読む処理が要らず、中身も確認しやすい。

- 変換には `@tonejs/midi`（Tone.js と同じ作者の公式ライブラリ）を使う案。**新しいライブラリなので、入れる前にチームで確認する**
- 時刻と長さは**拍**で持つ（秒にしない）。テンポを体験者に合わせて変えるため

```json
{
  "id": "A",
  "root": "D",
  "scale": "dorian",
  "bars": 20,
  "tracks": {
    "melody": [{ "beat": 0, "midi": 69, "dur": 1, "vel": 0.8 }],
    "pad":    [{ "beat": 0, "midi": [62, 65, 69], "dur": 8, "vel": 0.5 }],
    "bass":   [{ "beat": 0, "midi": 38, "dur": 2, "vel": 0.7 }],
    "kick":   [{ "beat": 0, "vel": 0.9 }],
    "snare":  [{ "beat": 1, "vel": 0.8 }],
    "hat":    [{ "beat": 0.5, "vel": 0.5 }]
  }
}
```

- `beat`: 曲の頭から何拍目か（0 から。20小節なら 0〜80 未満）
- `midi`: MIDI の音の番号（60 = C4）。パッドは配列
- `dur`: 長さ（拍）、`vel`: 強さ（0〜1）
- `root`・`scale`: 原曲のキーと音階。`scale` の名前は `src/blueprint.js` の `SCALES` に合わせる

## 4. 声で編集する3つの要素

使う声の特徴は `src/input/voice.js` がすでに出しているもの。

### 4-1. 声の高さ → キー

- 使う特徴: `pitchNote`（例: `"G#3"`）の音名部分（`"G#"`）
- 原曲をどれだけずらすか:
  ```js
  let shift = (NOTES.indexOf(voiceRoot) - NOTES.indexOf(song.root) + 12) % 12; // 0〜11
  if (shift > 5) shift -= 12;                                                  // −6〜+5 にする
  ```
- メロディ・パッド・ベースの全部の音を `shift` 半音ずらす（ドラムはずらさない）
- 上下どちらか近いほうにずらすので、原曲から最大半オクターブしか動かない

### 4-2. 声の高さの揺れ幅 → メロディの音域

- 使う特徴: `pitchVariation`（抑揚、0〜1）→ 設計図の `melodyRange`（0〜1）
- 伸び縮みの倍率: `factor = 0.6 + 0.8 × melodyRange`（抑揚が小さいと 0.6 倍、大きいと 1.4 倍）
- メロディの各音を、真ん中の音からの距離で伸び縮みさせる:
  ```js
  const center = median(melody.map(n => n.midi));          // 移調したあとのメロディの中央値
  let m = Math.round(center + (n.midi - center) * factor);
  m = snapToScale(m, root, scale);                          // 音階にない音は、一番近い音階の音に寄せる
  m = clamp(m, 55, 88);                                     // G3〜E6 に収める
  ```
- 変えるのは**メロディの高さだけ**。リズム・長さ・強さは原曲のまま
- 揺れ幅は人によって偏るので、実際の声をいくつか録って `pitchVariation` → `melodyRange` の対応を調整する

### 4-3. かすれ・息っぽさ → リバーブの深さ・パッドの柔らかさ

- 使う特徴: `clarity`（澄み具合。低いほどささやき・息まじり）→ 設計図の `breathiness = 1 − clarity`（0〜1）
- `breathiness` から音の設定を決める（間は直線で補間）:

| 設定 | breathiness = 0（はっきりした声） | breathiness = 1（息っぽい声） |
|---|---|---|
| リバーブの長さ（`Tone.Reverb` の `decay`） | 1.5 秒 | 6 秒 |
| リバーブの混ぜ具合（`wet`） | 0.15 | 0.5 |
| パッドの立ち上がり（`attack`） | 0.1 秒 | 1.5 秒 |
| パッドの消え方（`release`） | 0.8 秒 | 3 秒 |
| パッドのフィルター（ローパスの `frequency`） | 4000 Hz | 900 Hz |

- `clarity` の実際の値の幅は録音で確かめ、`breathiness` が 0〜1 に広がるように調整する

### 4-4. 声が取れなかったとき

| 要素 | 代わり |
|---|---|
| キー | 原曲のキーのまま（`shift = 0`） |
| 音域 | 原曲のまま（`factor = 1`） |
| 息っぽさ | 既定値 0.3 |

## 5. 原曲以外の材料の反映（曲1）

- テンポ: 拍で持っている時刻を、設計図の `bpm` で秒に直す（`秒 = beat × 60 / bpm`）
- ノリ: 拍の頭の音に `groove[拍 % 4]` 秒を足す
- 1問ごとの区間: 原曲の 2小節ずつが `q1`〜`q10` に当たる。`sections[i].energy` で強さを変えたり、ドラムを抜いたりする（任意）
- イントロ・アウトロ: 2小節ずつ、本人の声（`voice` トラック）だけ、または声＋パッド

## 6. 形の変更（相談して決めること）

### 設計図に足す項目（案）

| 項目 | 範囲 | 既定値 | 作る人 | 使う人 |
|---|---|---|---|---|
| `baseSong` | `"A"`〜`"D"` | `"A"` | 入力1（質問の答えから） | 曲1 |
| `melodyRange` | 0〜1 | 0.5（倍率 1.0） | 入力1（声の抑揚から） | 曲1 |
| `breathiness` | 0〜1 | 0.3 | 入力1（声の澄み具合から） | 曲1 → 曲2 |

- どれも既定値があるので、`docs/interfaces.md` の 10 では「項目を足す」に当たり、`version` は 1 のまま
- `src/blueprint.js` の `defaultBlueprint`・`normalizeBlueprint`・`SAMPLE_BLUEPRINT` と `docs/interfaces.md` の 5 を同じ PR で直す

### 意味が変わる項目

- `root`: 今は性格から決める決まり。**声の高さが取れたときは声から、取れなければ原曲のキーのまま**に変える
- `scale`: 原曲の音階を使うので、設計図の `scale` は使わなくなる（残すか消すかを決める。消すなら `version` を上げる）
- `density`: 原曲の音の数がもとになる。音を間引く・足すのに使うかを決める

### 楽譜に足す項目（案）

息っぽさを曲2に渡すため、楽譜に音の設定を足す。

```ts
Score.mix = {
  reverbDecay: 秒, reverbWet: 0〜1,
  padAttack: 秒, padRelease: 秒, padFilterHz: number,
}
```

- 数字の計算（4-3 の表）は曲1がしても曲2がしてもよい。どちらがするかを決める

## 7. 作る順番（案）

1. 原曲を1曲だけ MIDI で作り、JSON に変換して `src/music/songs/A.json` に入れる
2. 曲1: その JSON をそのまま楽譜にして鳴らす（編集なし）
3. 曲1: 移調 → 音域の変更を足す。`SAMPLE_BLUEPRINT` の値を変えて聞き比べる
4. 曲2: `mix` でリバーブとパッドを変える
5. 入力1: 声の特徴 → `melodyRange`・`breathiness`・`root`、質問 → `baseSong`
6. 残りの3曲を作って入れ替える
